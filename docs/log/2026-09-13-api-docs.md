# 2026-09-13 — API docs: `spec/openapi.yaml`, `/api/openapi.json`, `/api/docs`, contract test

Branch `feat/api-docs` (PR into `develop`), Wave 2, on top of the job API,
security phase B and observability phase B. Changes what is runnable: the
server now describes itself, and a test fails whenever a route and the
description disagree. `STATUS.md` gained one line.

## What was done

- `spec/openapi.yaml` — hand-authored OpenAPI 3.1 (Starlette has no
  generator) for every route `api.app.create_app()` registers: the jobs API,
  the six legacy root scene routes, the job-scoped mirrors and the `307`
  redirect, `/metrics`, and the two new description routes. The scene body is
  a `$ref` to `./scene.schema.json` (the frozen contract is referenced, never
  copied); the job record schema is `JobRecord.to_dict()` with
  `additionalProperties: false`; SSE is `text/event-stream` with the three
  event names and their payload schemas; `/metrics` is `text/plain` with the
  `version=` parameter explained; `securitySchemes.bearerAuth` plus the open /
  keyed policy in the `info.description`; one `ErrorEnvelope` and an
  `ErrorCode` enum with a status-by-code table.
- `src/api/routes/docs.py` — `GET /api/openapi.json` (the YAML loaded once,
  served as JSON) and `GET /api/docs` (a static Redoc page; the bundle loads
  from `cdn.jsdelivr.net` **in the browser**, so the page needs network at
  view time, and it shows a fallback paragraph pointing at the JSON when the
  script fails). Registered in `app.py` as one import + `docs_routes()`,
  between `/metrics` and the job-scoped routes.
- `src/api/security/auth.py` — `PUBLIC_PATHS = {"/api/openapi.json",
  "/api/docs"}` stay open in keyed mode (they contain nothing that is not in
  the public repo); `SOBA_AUTH_LEGACY=1` still closes them. Four lines.
- `tests/api/test_openapi.py` — the contract test, three layers: (a) the
  document validates (`openapi-spec-validator`, now in the `dev` extra) and
  every `$ref` resolves including the scene schema; (b) `create_app().routes`
  walked recursively vs `paths`, both directions, with the static
  `frontend/dist` mount as the only allowed undocumented leaf; (c) live
  responses validated with `jsonschema` against the response schemas: the job
  lifecycle (create / list / get / redirect / viewer / scene / eval / mesh /
  hull / delete / 404 after delete), the upload rejections (415, 400 x2,
  422), the unknown-job envelopes on every job-scoped path, keyed-mode 401s
  (and the docs routes staying open, and closing under `SOBA_AUTH_LEGACY=1`),
  `429` with `Retry-After`, `/metrics` (200 or 501), the docs routes. The
  `ErrorCode` enum is asserted equal to the set of codes `src/api` can raise.
  An optional `schemathesis` run (marker `schemathesis`, skipped when the
  package is absent) fuzzes every documented `GET` with five examples each;
  it ran here in about 4 s.
- `docs/api.md` — auth modes, upload contract, job lifecycle, SSE, rate
  limiting, the error table, a curl walk-through, how to keep the spec honest.
- `README.md` Documentation list, `STATUS.md` current-state block: one line each.

## Decisions and findings

- **Legacy plain-text 400/404s carry no `Content-Type` header.**
  `routes/scene.py` builds them with bare `starlette.Response(...)`. The
  spec documents them as `text/plain` and says the header is absent; the
  contract test treats an absent header as matching `text/plain` only, and
  the schemathesis run waives `content_type_conformance` for exactly those
  responses. Not changed in code: the job-api brief says the legacy routes
  stay byte-for-byte as they were. A `PlainTextResponse` would be the one-word
  fix if that rule is ever relaxed.
- **`/metrics` stays unauthenticated in both modes**, as `STATUS.md` records;
  the spec says so in the operation description rather than pretending
  otherwise.
- **The empty-scene fallback** (`{"version": "2.0", "objects": []}`) does not
  satisfy the frozen schema (known defect in `STATUS.md`). The spec models
  the scene body as `anyOf [Scene, EmptyScene]` so the live response still
  validates while the defect stays visible.
- `/api/jobs` `GET` (list) is documented; the route list handed over did not
  mention it but the code has it.
- No new runtime dependency: `pyyaml` was already core. `openapi-spec-validator`
  joins the `dev` extra; `schemathesis` is deliberately in no extra (it pulls
  in hypothesis and friends) and the test skips without it.

```bash
pytest -q tests/api                       # 18 new tests in test_openapi.py
python scripts/serve.py --scene out/scene_test

```
