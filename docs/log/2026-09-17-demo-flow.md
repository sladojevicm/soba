# 2026-09-17 — Conference demo flow (`/?demo`) and a truthful gate label

Client-side only; no GPU, no backend job. Built and checked on the WSL box against the curated
office_3 scene from run 9 (`out/demo/office_3_curated`, 8 of the run's 12 objects, see its
`CURATED.md`).

## What is new

* **`GET /run_metrics.json`** (root and `/jobs/{id}/`): serves the scene dir's telemetry, or
  `{"available": false}` (same contract as `/eval.json`; in `spec/openapi.yaml`).
* **Inspector tells the truth.** `scene.json`'s frozen `geometry_source` is `tsdf | generative`,
  so every PatchComplete-completed object used to read "keep · fused tsdf". The route, coverage
  and completeness now come from `run_metrics.json` (`frontend/src/pipeline.ts`); without it the
  label falls back to "measured · tsdf". The schema is untouched.
* **`/?demo`**: upload screen → presenter-paced staged replay → the viewer. `/` is still the
  plain viewer (`scripts/verify_browser.js` passes unchanged; `window.__soba` shape unchanged).
  * Upload: drag-drop or picker, shows name/size and plays a video locally. The file never leaves
    the browser; the headless walk-through saw zero non-GET requests. Copy says "RGB-D capture".
  * Staged replay: the three contexts with the numbers the recorded run wrote (gate 0/12/2,
    PatchComplete 11 fused, CoACD 12, stage seconds). Nothing animates on its own; a permanent
    banner reads "Staged replay of a run recorded on 17 September 2026. The real run took
    17 min 35 s on one GPU. Nothing is computed live."
  * Reveal: presentation mode (root font scale 150 %, panels replaced by a story card that keeps
    "recorded 17 September 2026" on screen), room framed, slow orbit until the camera is touched.
* **Viewer additions** (store actions only; React still never touches Three/Rapier):
  `setAutoOrbit`, `focusObject` (eased dolly, keeps the viewing direction), `setTints`,
  `resetObjects` (pose restored, at rest, FIXED again, balls removed).
* **Colour modes** (`c`): by material class, by gate route, off. Tokens `--color-mat-*` and
  `--color-route-*`, mirrored as hex in `pipeline.ts` because the viewer cannot read CSS (same
  arrangement as the selection accent). Tinted meshes are rendered dielectric: the untextured
  pipeline meshes get GLTFLoader's default metalness 1, which has no diffuse term. Untinted
  rendering is exactly as before.
* `serve.py --scene <not a directory>` now exits with an error instead of serving an empty room.

## Presenter notes

```bash
source .venv/bin/activate
python scripts/serve.py --scene out/demo/office_3_curated      # then open http://127.0.0.1:8000/?demo
```

| key | does |
|---|---|
| `enter` (upload) | start the staged replay once a file is chosen ("continue without a file" is the fallback) |
| `→` / `←` (replay) | next / previous context; after Scene assembly, `→` opens the scene |
| `→` / `←` (scene) | tour: select and frame the next / previous object; past the end returns to the room |
| `f` | whole room · `o` slow orbit · `c` colour: material → gate route → off |
| `r` | put everything back after throwing things · `space` drop a ball · drag = push |
| `p` | leave / enter presentation mode (full panels) |

Say out loud what the screen says: the run is recorded, 8 of 12 objects are shown (4 removed by
hand: three chairs whose base or legs were never observed, one whose backrest sealed into a
slab), and this capture is a Replica RGB-D render with ground-truth masks and poses. In the
curated scene all 8 objects took the completion route, so "colour by gate route" is one colour;
"by material" is the more useful view. The original 12-object scene
(`out/pod_20260917/office_3`) has the one generated chair.
